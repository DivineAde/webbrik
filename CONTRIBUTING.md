# Contributing to Webbrik

Thanks for helping. Please read this before opening a pull request.

## Ground rules
- Open an issue first for anything bigger than a small fix, so we agree on the direction before you spend time.
- Keep changes focused: one fix or feature per pull request, with tests.
- Run `pnpm typecheck` and `pnpm test` before you push. CI runs them again.
- Follow the existing code style and the visual language in [DESIGN.md](DESIGN.md).

## Reporting a security problem
Please do not open a public issue. See [SECURITY.md](SECURITY.md).
