# ADR-0022: API logging
Status: accepted. Nest's default logger was silenced by the bootstrap, so startup failures and requests were invisible. `ApiLogger` keeps framework chatter (instance loading, route mapping) quiet, always prints errors and warnings, and `requestLogger()` prints one line per request (`METHOD path status ms`; 5xx as errors, 4xx as warnings; successful health/ops/realtime GETs hidden unless debug). `main.ts` prints a startup banner (address, storage without credentials, web origin, email, payments, AI, publishing) and, if startup fails, the error plus a hint for common causes (bad database credentials, unreachable host, SSL, port in use) and exits non-zero. `LOG_LEVEL` (error|warn|log|debug) and `LOG_REQUESTS=0` control it; tests run silent.
