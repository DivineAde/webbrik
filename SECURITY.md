# Security policy

## Reporting a vulnerability
Please report security problems privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue or pull request for it.

Include what you found, how to reproduce it, and what it could affect. You will get an acknowledgement, and a fix or an explanation, as quickly as one person can manage. Please give a reasonable time to fix the problem before you publish details.

## What is covered
The code in this repository. Hosted copies run by other people are their operators' responsibility.

The security design is described in [docs/architecture/security-model.md](docs/architecture/security-model.md).
